الآن دور عرضك

أجب عن أسئلة قصيرة في الأسفل، وخذ مطالبتك.

عرض كامل، ومعه أدواته

أجب عن أسئلة قصيرة أو ارفع عرضك الحالي. كلاكيت يكتب لك مطالبة جاهزة تلصقها في وكيل برمجة، فيبني لك عرضًا كاملًا بهذه الطريقة، ومعه نافذة للمقدّم وملف PDF ونسخة احتياطية.

  • الناتج صفحة ويب تعمل دون إنترنت، وليس ملف PowerPoint.
  • تحتاج وكيل برمجة باشتراك مدفوع، مثل Claude. الدليل يشرح البداية.
  • ملفك لا يغادر جهازك. القراءة تتم داخل متصفحك.

من المطالبة إلى العرض

وكيل البرمجة برنامج ذكاء اصطناعي يعمل على حاسوبك: ينشئ الملفات ويشغّل الأوامر داخل مجلد تختاره. هذا الدليل يشرح البداية بتطبيق Claude لسطح المكتب، وهو الوكيل الذي اختُبرت عليه المطالبة.

ما تحتاجه

  • اشتراك مدفوع في Claude: Pro أو Max أو Team أو Enterprise. الخطة المجانية لا تكفي.
  • حاسوب Windows أو Mac، ومتصفح Chrome أو Edge لتشغيل العرض.
  • على Windows فقط: برنامج Git for Windows. ثبّته بالإعدادات الافتراضية قبل البدء.

ثبّت التطبيق

  1. نزّل تطبيق Claude من claude.com/download وثبّته.
  2. افتحه وسجّل الدخول بحسابك.
  3. اضغط تبويب Code في أعلى الوسط. إن طلب منك الترقية فاشتراكك لا يشمله.

جهّز المجلد

  1. أنشئ مجلدًا جديدًا فارغًا، وسمّه بحروف إنجليزية مثل my-talk.
  2. إن كان لديك عرض جاهز فانسخ ملفه إلى المجلد، ليأخذ الوكيل الصور منه.
  3. في التطبيق اختر Local ثم Select folder وحدّد المجلد.

الصق المطالبة

  1. الصق المطالبة كاملة في خانة الكتابة واضغط Enter.
  2. سيطلب الوكيل إذنك عند إنشاء ملفات أو تشغيل أوامر. هذا متوقع، وكل عمله يبقى داخل مجلدك.
  3. يشرح خطته باللغة التي اخترتها، ثم يتوقف وينتظرك.

البوابات الأربع

الوكيل لا يبني كل شيء دفعة واحدة. يتوقف بعد كل مرحلة ويعطيك قائمة قصيرة تجرّبها، ولا يكمل حتى توافق. توقّفه ليس عطلًا.

  1. الخطةيبني: ثلاثة اتجاهات بصرية بألوانها وخطوطها، وتقسيمًا مقترحًا لشرائحك.عليك: اختر اتجاهًا وأجب عن أسئلته.
  2. المحركيبني: التنقل وأزرار التحكم وصفحة اختبار.عليك: جرّب جهاز التقليب، واضغط D لترى ماذا يرسل كل زر.
  3. الشكليبني: الخلفية المتحركة والألوان وأول شريحة حقيقية.عليك: احكم على المظهر، وافتح اختبار السرعة الذي يدلّك عليه.
  4. الأدواتيبني: نافذة المقدّم، وملف PDF، ونسخة احتياطية تعمل على أي حاسوب.عليك: تمرّن بشاشتين إن أمكن، وافتح النسخة الاحتياطية.

بعد البوابات ترسل شرائحك على دفعات. إن لم يعجبك شيء فأرسل لقطة شاشة وقل ما الخطأ فيها.

يوم العرض

  • افتح index.html بنقر مزدوج، ثم اضغط F لملء الشاشة وH لقائمة الأزرار.
  • للخروج من ملء الشاشة اضغط F، أو اضغط Esc مطوّلًا.
  • انسخ المجلد كاملًا إلى ذاكرة USB، ومعه النسخة الاحتياطية وملف PDF.
  • جرّب العرض على حاسوب القاعة قبل الموعد.

      أستخدم وكيلًا آخر أو سطر الأوامر
      
المطالبة مكتوبة لأي وكيل برمجة ينشئ الملفات ويشغّل الأوامر على حاسوبك، مثل Codex و Kimi Code. اختُبرت على Claude Code فقط.

      
لتثبيت Claude Code في سطر الأوامر بدل التطبيق:

      
macOS

      
curl -fsSL https://claude.ai/install.sh | bash

      
Windows، في PowerShell

      
irm https://claude.ai/install.ps1 | iex

      
ثم افتح سطر الأوامر داخل مجلدك واكتب claude.
